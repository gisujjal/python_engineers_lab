# Python Advanced Engineering Laboratory

Welcome to my deep-dive laboratory into the internal mechanics, architecture, and advanced design patterns of the Python programming language. 

This repository serves as a structured portfolio demonstrating low-level language concepts, memory optimization, and advanced engineering patterns.

## 🗂️ Lab Directories

### 🧪 [01. Closures & Decorators](./01_closures_and_decorators/)
- **Concepts:** Memory heap variable escape, Cell objects, multi-layer functional factories, and structural metadata preservation (`functools.wraps`).
- **Core File:** `closure_factory.py`

### ⚡ [02. Async & Concurrency](./02_async_and_concurrency/)
- **Concepts:** The Event Loop, non-blocking I/O operations, co-routines, and task scheduling.

### 📦 [03. Generators & Custom Iterators](./03_generators_and_iterators/) *(In Progress)*
- **Concepts:** Lazy evaluation pipelines, memory-efficient data streaming, and the `yield` expression state-machine.
